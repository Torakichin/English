# 中学英語 4択トレーニング

中学1年生〜中学3年生の英文法を、4択問題形式で学習できるシンプルなWebアプリです。

HTML / CSS / JavaScriptのみで作成しており、ブラウザ上で動作します。  
PCだけでなく、iPhone・Androidなどのスマートフォンからの利用も想定しています。

## 概要

スタート画面から学年を選択し、各学年の英文法問題に挑戦できます。

問題はすべて4択形式になっており、回答するとその場で正誤と解説を確認できます。

各問題セット終了後には、

- 正解数
- 正答率に応じたメッセージ
- 間違えた問題
- 自分が選んだ回答
- 正しい回答

を確認できます。

- 現在進行形

- be動詞の過去

## 主な機能

### 学年選択

`index.html` を開くとスタート画面が表示されます。

「中学1年生」「中学2年生」「中学3年生」のボタンから、それぞれの学習画面へ移動できます。

### 単元選択

各学年のページでは、学習したい英文法の単元を選択できます。

さらに単元内の問題セットを選択して学習を開始できます。

### 4択問題

すべての問題を4択形式に統一しています。

英作文や語句選択なども、スマートフォンで回答しやすいよう4択問題として構成しています。

### 即時採点

選択肢を押すと、その場で

- ○ 正解
- × 不正解
- 正しい答え
- 簡単な解説

が表示されます。

### 学習結果

問題セット終了後に正解数を表示します。

間違えた問題については、自分の回答と正解を一覧で確認できます。

「もう一度」を押すことで、同じ問題セットに再挑戦できます。

## ファイル構成

```text
English/
│
├── index.html
├── 1.html
├── 2.html
├── 3.html
├── back.jpg
└── icon.png
```

各ファイルの役割は以下の通りです。

| ファイル | 内容 |
|---|---|
| `index.html` | 学年を選択するスタート画面 |
| `1.html` | 中学1年生の英語問題 |
| `2.html` | 中学2年生の英語問題 |
| `3.html` | 中学3年生の英語問題 |
| `back.jpg` | スタート画面の背景画像 |
| `icon.png` | ホーム画面・ブラウザ用アイコン |

## 使い方

基本的には `index.html` をブラウザで開くだけで利用できます。

1. `index.html` を開く
2. 学年を選択する
3. 学習したい単元を選択する
4. 問題セットを選択する
5. 「スタート」を押す
6. 4択問題に回答する
7. 終了後に学習結果を確認する

## スマートフォン対応

レスポンシブデザインにしているため、PCだけでなくiPhoneやAndroidからも利用できます。

スマートフォンのブラウザからホーム画面へ追加することで、通常のアプリに近い感覚で起動することもできます。

`icon.png` をホーム画面用アイコンとして設定しています。

## 技術構成

特別なフレームワークやライブラリは使用していません。

- HTML
- CSS
- JavaScript

のみで構成しています。

問題データもJavaScript内に保持しているため、データベースやWeb APIは必要ありません。

## 特徴

このアプリでは、できるだけ構成をシンプルにしています。

サーバー側の処理やデータベースを使用せず、HTMLファイルを中心に動作するため、Web開発環境を準備しなくても利用できます。

また、問題を4択形式に統一することで、PCだけでなくスマートフォンでも簡単に学習できるようにしています。

## 問題について

英文法の単元構成・学習範囲については、005netの中学生向け英語学習コンテンツを参考にしています。

問題文・選択肢・解説は、本アプリ用のオリジナル問題として作成しています。

## 注意事項

本アプリは個人学習・プログラミング学習を目的として作成したものです。

学習内容については、中学校で一般的に扱われる英文法をベースとしていますが、学校・教科書・学習時期によって単元の分類や学習順序が異なる場合があります。
